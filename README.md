# Teacher Report AI — GitHub Pages

ไฟล์ในโฟลเดอร์นี้พร้อมสำหรับ GitHub Pages

## วิธีขึ้นเว็บ
1. สร้าง Repository ใหม่ใน GitHub เช่น `teacher-report-ai`
2. อัปโหลดไฟล์ `index.html`, `manifest.webmanifest`, `sw.js` ไปที่ root ของ repository
3. เปิด Settings → Pages
4. Source: Deploy from a branch
5. Branch: `main` และ Folder: `/ (root)`
6. กด Save
7. รอ GitHub สร้างลิงก์เว็บ เช่น `https://USERNAME.github.io/teacher-report-ai/`

## ใช้บน iPhone
เปิดเว็บด้วย Safari → Share → Add to Home Screen

## หมายเหตุ
- ข้อมูลรายงานเก็บด้วย LocalStorage ในเครื่อง/เบราว์เซอร์ของผู้ใช้
- เวอร์ชันนี้ยังไม่เชื่อมฐานข้อมูลออนไลน์หรือ AI API จริง
- ถ้าล้างข้อมูล Safari/Chrome ข้อมูล LocalStorage อาจหายได้
